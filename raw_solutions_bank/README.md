### How Pairing Works:
* If an image in `raw_questions_bank/physics_1st_paper/01.jpg` has a matching solution image in `raw_solutions_bank/physics_1st_paper/01.jpg`, the system automatically pairs them together.
* The question is extracted from the question image, and the **official teacher/textbook solution** is extracted word-for-word from the solution image!
